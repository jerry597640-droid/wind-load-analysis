# 建築風力分析

臺灣建築物耐風設計規範 103 年版計算工具。

## 使用
以 Chrome 或 Edge 開啟 index.html，可完全離線計算。GitHub Pages 請選 Deploy from a branch、main、/(root)。

## 功能
- 普通矩形平屋頂建築物順風向風載
- 開放式結構係數輸入法
- 局部構材與被覆物風壓
- 23 個欄位定義與填值提示
- 即時計算、風壓圖與詳細公式

## 適用限制
不包含柔性建築物動態分析、橫風向、扭轉、風力組合、層間變位、加速度及構件強度檢核。Cf、GCp 與工址風速須依適用規範查定；示例輸入值不等於設計建議值。

規範參考連結需連網。
